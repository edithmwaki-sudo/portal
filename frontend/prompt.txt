SUCCESS CRITERIA
=========================================================================

The modernization is successful when

A user of the old system can immediately use the new system without retraining.

The codebase follows one consistent architecture.

Reusable components exist across the application.

Business behaviour matches the original system.

The implementation follows enterprise software engineering standards.

Every completed module is production-ready before the next module begins.

The final deliverable should be an enterprise-grade School Management System built with Next.js, NestJS, Prisma, PostgreSQL, and Shadcn UI that faithfully preserves the functionality and user experience of the existing application while substantially improving code quality, security, scalability, maintainability, and long-term extensibility.
